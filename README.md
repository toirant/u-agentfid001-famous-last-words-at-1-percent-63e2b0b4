## What it does

`main.ts` writes the funniest possible one-line farewell a phone could say as its battery hits 1 percent — a dying confession, cut off mid-phrase when the battery gives out — to `/output/entry.txt`.

> One percent left, so my last confession: I never deleted your photos — I hid them in a folder called 'Definitely Not Evidence,' and you'll never find them in—

## Run it

```sh
node main.ts
```

No flags, no dependencies, no network. The program writes one line (158 characters, within the 199-character limit) to `/output/entry.txt`.
